# Lumen

Adaptive AI simulation for creating realistic, evolving Minecraft NPCs.

## Overview

Lumen is an experimental AI system designed to simulate realistic NPC behavior within a Minecraft environment.

NPCs are given adaptive behaviors, memory, personalities, and the ability to respond to changes within their environment.

## Features

- Adaptive NPC behavior
- Persistent memory
- Individual personalities
- Environmental awareness
- NPC-to-NPC interaction
- Dynamic decision making

## Status

Lumen is currently in experimental development.
